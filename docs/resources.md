# 第一轮资源估算

首轮输入224×224，DenseNet201加8参数头共18,337,352参数。参数、梯度、Adam两个状态按FP32粗算约280MiB；实际显存主要来自中间特征、算子工作区与运行时，需以100步训练实测为准，不能只按权重文件大小选GPU。

## 租机选择

如需租机，选 **1×RTX4090 24GB、至少8 vCPU、32GB RAM、50GB可用磁盘**。第一轮不需要多卡或A100。3090 24GB也足够；只有价格/库存更合适时再选它。

2026-09-21 [AutoDL官网](https://www.autodl.com/)展示4090约1.88元/小时、3090约1.32元/小时。按4小时预算，分别为 **7.52元、5.28元GPU费**；4小时是含安装、验证的预算额度，不是实测训练耗时。存储等费用另计，具体卡型可用性、CPU/RAM配额和价格以[市场下单页](https://www.autodl.com/market/list)为准，参见[计费说明](https://www.autodl.com/docs/price/)。

空间估算：环境/依赖及下载缓存约10～15GB，224像素缓存约0.65GiB，数字原片约1.8GiB，已有权重约0.21GiB，两份微调权重及优化器状态预留1GB，背景/日志/开发图预留数GB，50GB有足够余量。线上训练不需要保存海量合成图；合成在CPU在线完成。

## 本地先测

本机为RTX 3000 Ada笔记本GPU，8GB显存、约30GiB系统内存。先实测batch=8、混合精度、最后块微调100步，剔除10步图编译与热身。结果写 `.local/benchmark.json`。若本机一轮可在合理时间完成，首轮直接本地跑，避免为这次小实验租机和搬运数据。

## 100步实测结果

最终运行Keras 3.15.1 + PyTorch 2.12.1+cu130，网络和权重严格保持PTRN约定。TensorFlow GPU依赖下载过慢，改用本机已有PyTorch运行库；独立环境未修改旧项目安装。

| 项目 | 实测 |
|---|---:|
| GPU | RTX 3000 Ada Laptop 8GB |
| batch / 精度 | 8 / mixed_float16 |
| 训练参数 | 6,896,648（最后DenseNet块与输出头，BN冻结） |
| 平均每步 | 0.202秒 |
| 每步P90 | 0.207秒 |
| PyTorch峰值分配显存 | 1750MiB |
| PyTorch峰值预留显存 | 1846MiB |
| 外推3000步 | 约10.1分钟，不含开发验证/写权重 |

**决定：第一轮在本机执行，没有创建付费实例，租机支出为0。** 4090配置保留给后续更大分辨率、多组消融或更长训练。首次环境准备时间与训练时间分开记录，不据下载耗时判断GPU不足。

实际训练3000步及阶段验证共 **808秒，约13.5分钟**，比只按训练步外推的10.1分钟多出验证、写权重和持续运行开销。完整训练峰值已分配显存1819MiB，峰值预留1918MiB。首次环境准备和最终47张图片生成不计入训练时长。

## B1.1：本机批量选择

2026-09-21在新的30%恒等、60%轻微、10%较大变形采样下，最后块微调各测100步，另排除10步热身：

| batch | 平均秒/步 | 样本/秒 | 峰值已分配 / 预留显存 |
|---|---:|---:|---:|
| 8 | 0.2067 | 38.70 | 1733.5 / 1808MiB |
| 16 | 0.2092 | 76.47 | 3214 / 3366MiB |

因此B1.1选择本机batch=16，没有租机或上传。按测速外推5000步纯训练约17.4分钟，三组验证、写权重等另计；实际完整耗时以运行摘要为准。测速记录在`.local/runs/b1-1/benchmark-batch8.json`及`benchmark-batch16.json`，没有覆盖首轮记录。

实际5000步训练及周期验证1690.5秒，约28.2分钟；峰值已分配3526MiB、预留3806MiB。最终FP32评估和47张图片生成另计。详见[B1.1结果](second-run.md)。
