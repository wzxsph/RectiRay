# 拍摄干扰 v1

> 本文记录独立 100 张外观预览阶段；“尚未批准训练使用”等措辞只代表该阶段。当时样例与后续统一训练配方应分开，当前状态以仓库 [README](../README.md) 和运行绑定为准。

本轮实现独立的 `ptrn-capture-appearance-v1` 外观合成和本地审阅网页，尚未批准训练使用。未修改模型架构、权重、旧合成实现、固定开发场景或应用接口，未启动训练或模型推理。样例真实性由用户判断，不以像素变化统计代替人工审阅。

## 数据与配额

复用现有 147 张比较网页中全部 100 张合成样例的母片、场景种子、四角、前后裁剪、背景来源和占幅。它们是已暴露开发数据；不是新增独立测试集。生成时重新运行旧合成器，核对旧网页输入像素和完整几何元数据，然后重建未添加旧外观增强的场景。**不能简单把旧 `level` 改成 `clear`**：外观随机数消耗影响后续裁剪采样。新实现直接复用已保存的后裁剪坐标。

| 介质 | 清晰 | 轻度 | 中度 | 较强 | 合计 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原片保留 | 20 | 0 | 0 | 0 | 20 |
| 屏幕 | 8 | 24 | 7 | 1 | 40 |
| 实体胶片 | 8 | 24 | 7 | 1 | 40 |

每种拍摄介质分别有 16 张框式屏幕／观片灯、10 张 COCO、10 张同色和 4 张混色背景。介质先在各背景内独立打乱平分，再用独立随机流分配强度；不根据生成结果挑图。保留原来的 48 个完整、24 个轻缺损、8 个中缺损拍摄场景及 20 个母片预裁剪场景。80 张拍摄图最小占幅 31.06%，70 张占幅超过 50%。几何与外观随机流不共享，轻几何也可以分配中强外观。

## 外观实现

代码：[capture_synthesis.py](../src/ptrn_hip/capture_synthesis.py)；生成入口：[capture_review.py](../src/ptrn_hip/capture_review.py)。原有三个合成模块作为只读几何依赖，构建报告保存其 SHA。

| 效果 | 作用范围与实现 |
| --- | --- |
| 灰度／彩色摩尔纹 | 仅屏幕表面。逆映射到平面坐标后合成多尺度条纹、略有频差的网格拍频和彩色相位；经照片采样和网络补边缩放。不是随机噪声替代。 |
| 明暗条带 | 仅屏幕表面，独立方向与频率的亮度变化。 |
| 观片灯不均匀 | 胶片表面平滑亮度梯度与缓慢衰减。 |
| 窗户、灯条倒影 | 相应表面内的程序化窗格或灯条，窗格边缘可清晰或柔化。近似线性光域相加后编码、裁到动态范围，允许局部饱和。 |
| 雾状反射、局部高光 | 相应表面的平滑反射场与集中亮斑，不生成被遮住的医学内容。 |
| 失焦、手抖 | 整张照片，高斯点扩散或方向线核；核大小按照片尺寸换算，避免所有效果缩到 224 后消失。 |
| 噪声、曝光、白平衡、JPEG | 整张照片，分别使用噪声、增益、通道增益和实际 JPEG 编解码。 |

轻度最多两项，中度和较强最多三项；清晰无叠加。当前审样配方明确覆盖各效果，而不是让小批量的随机碰巧遗漏某项。胶片配方禁止摩尔纹及显示条带。每张的完整参数和每个效果的独立种子都写入清单。

表面与背景独立：带查看器的屏幕采用原显示表面掩码；COCO／同色／混色的屏幕采用“影像填满显示区”的表面模型，当前只建模可见影像区域，不额外臆测显示器边框。胶片反射作用于胶片掩码。框式胶片场景把原屏幕工具栏区替换为观片灯边框；清晰与干扰图均采用这一背景，底片几何不变。**这仍是程序化近似，不是标定的光学仿真**；没有宣称解决实拍域差异。

摩尔纹的多频段设计参考 [Sun 等人的研究](https://arxiv.org/abs/1805.02996)，该文讨论显示器与传感器采样干涉及其跨频率特性。本实现不是论文复现。用户提供的 [反射研究](https://openaccess.thecvf.com/content_CVPR_2019/papers/Wen_Single_Image_Reflection_Removal_Beyond_Linearity_CVPR_2019_paper.pdf) 是后续参考；本轮其网站访问失败，没有将未经核对的具体方法写成已实现。

## 网页及记录

本地产物目录为 `.local/capture-appearance-v1/review-100/`：

- `index.html`：清晰图、干扰图、真实 224 输入三栏。224 采用同一 `letterbox` 函数，展示图可切换到清晰 224 输入。
- `manifest.local.json`：100 个样例的来源哈希、种子、配方、参数、表面类型、原几何、图像及几何文件哈希。
- `images/`：500 张无损 PNG，包括两种照片、两种 224 输入及表面掩码预览。可点击查看原尺度。
- `geometry/`：100 个 NPZ，保留原精度的底片掩码、表面掩码、四角、比例、变换与补边变换。
- `technical-check.local.json`：配额、实际增强覆盖、像素活动和冻结文件校验；这些不是质量成绩。

支持介质、强度、效果、背景和审阅状态筛选；可选“自然可保留、太弱、太强、不像真实拍摄、不确定”，并写备注。判断尝试保存在浏览器 `localStorage`，同时可导出 JSON；浏览器不支持本地保存时会提示，仍可导出。导入检查版本和渲染代码 SHA，同编号覆盖为导入值。所有数据、图片与判断只留本地，无远程资源依赖。

## 复现与技术验收

在研究工作树根目录，以包含 NumPy、OpenCV、pytest 的 Python 环境运行；无需 CUDA、Keras 或模型权重。

```bash
PYTHONPATH=src python -m pytest tests/test_capture_synthesis.py -q
PYTHONPATH=src python -m ptrn_hip.capture_review \
  --report .local/pipeline-v1/gallery-147/report.local.json \
  --bundle .local/deploy/autodl-20260925/kit \
  --backgrounds "$CAPTURE_BACKGROUND_ROOT" \
  --output .local/capture-appearance-v1/review-100-reproduced \
  --workers 4
```

`CAPTURE_BACKGROUND_ROOT` 指向已授权的背景集根目录，内部路径取背景清单。输出必须是新目录；遇到已有目录或任一图的活动检查失败时直接报错，不覆盖旧图、不删难图重抽。随机种子及输入绑定相同、依赖版本相同，应复现相同像素。当前生成环境 NumPy 2.4.6、OpenCV 4.13.0。

本轮 25 个单元测试通过，覆盖确定性、不修改输入、原片逐像素保留、胶片禁摩尔纹、叠加数量上限、表面效果不泄漏、相机效果作用于背景、空掩码报错，以及全部四种背景上缺损场景的几何复现。100 张真实母片派生样例全部通过构建检查：旧输入与几何精确核对、原始文件哈希不变、500 张 PNG 编解码一致、120 次效果在原尺度和 224 都有像素变化。原片与清晰样例无效果是预期行为，不应误报。

另外从落盘清晰图、NPZ 与参数清单重放全部 100 张，干扰照片及 224 输入逐像素相同，600 个资产哈希一致。网页脚本通过语法、100 行生成、筛选、备注保存、判断导入导出往返及版本不匹配拒绝检查。结果另存 `replay-check.local.json`；这些是无浏览器渲染的逻辑检查。

像素活动只检查“没有完全消失”，不证明强度肉眼足够或外观自然；较强图全部保留供人工判断。浏览器视觉排版及主观真实性未作为上述技术测试通过的结论。旧训练数据、5736 张固定开发场景和旧网页没有更换；云端本轮无操作。

下一步先收集用户审阅，冻结配方后再安排训练对照；暂不选择 1250／5000 步起点，也不把拍摄干扰不足认定为唯一原因。
