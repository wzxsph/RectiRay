# PTRN Hip：髋关节 X 光照片取图研究

本仓库研究从手机拍摄的照片中定位 X 光片、去除外部背景，并在需要时摆正或透视校正。最终影像只从输入照片采样，不补造缺失的医学内容。本仓库独立于临床标注软件；研究权重不会自动替换应用模型。

**当前状态（2026-09-26）：**以旧正式训练 `step-2000.pt` 为父检查点、采用较轻缺损和更多近满幅拍摄图的新分支已经产生多个阶段的权重。用户目视偏好 **+2250**，它只是使用已暴露合成开发集和实拍资料挑选的**研究候选**，并未通过独立真实照片验收或取得应用准入。`+2250` 表示新分支从父检查点再更新 2250 步，不是旧训练的绝对 2250 步；不能与旧 `step-2250.pt` 混称。权重及其 SHA 对应关系应从受控备份和本地运行绑定核验，不放入普通 Git。

当前 V3 路径为：等比例补边的 RGB 输入 → DenseNet201 与四尺度空间特征融合 → 有序四角、完整参考平面的宽高比，以及用于内部监督的可见区域掩码 → 从原照片一次取图。掩码不是再次裁图的门禁。照片缺边、缺角时，输出只包含实际拍到的影像，缺失区域保持为空。可信数字原片走逐像素保留路径；**仅有标注或未启用额外裁剪，并不能证明输入就是数字原片**，手机翻拍和其他图像需按来源另行判断。

- [协作规范](AGENTS.md)与[外部来源及许可](THIRD_PARTY.md)：数据、权重、病例图和代码许可的边界。

最小代码环境为 Python 3.11 或 3.12、PyTorch 与 Keras 3 的 PyTorch 后端；GPU 训练需 BF16 可用的 CUDA 设备。只运行不接触病例数据的测试：

```bash
uv venv --python 3.12
uv pip install --python .venv/bin/python -e '.[dev]'
CUDA_VISIBLE_DEVICES='' KERAS_BACKEND=torch .venv/bin/python -m pytest -q
```

实际训练需要另行放置获准使用的母片、背景和初始化权重；仓库里没有这些文件。运行前核对数据划分、内容授权、SHA 和本机资源。具体命令见[复现指南](docs/reproducibility.md)。
仓库示例和 CI 仅使用合成夹具；如需展示公开数据集生成的照片，须先核实原片与背景的再分发许可，再在本地生成。47 张实拍及其逐例网页始终不上传。

## 如何理解结果

固定开发集含 478 张源片、每片 12 个场景，共 5736 个已暴露视图；训练池有 4114 张，另有 28 张隔离源片。开发集可比较候选，但不能代表独立患者或新手机场景。现有 47 张实拍也已用于多轮研究与人工挑选，不是独立测试。v1.1.0 标注图混有数字原片、手机翻拍及可能不属于目标髋片的图像；不能把整个集合的“排除画幅面积”当作漏片率，边缘关键点的越界也要结合实际影像检查。

选权重时优先避免切掉有效影像和错误形变，允许少量背景；同时检查方向、长宽比和可靠数字原片的保留。损失下降、合成指标改善、逐例目视可用与应用准入是不同结论。关于 +2000 到 +3000 的新分支及更早的 B1.1、统一头和空间 v2 实验，按[文档索引](docs/README.md)分别查阅，旧记录不作为当前部署建议。
